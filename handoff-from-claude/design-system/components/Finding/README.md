# Finding

What one block of the data says: a label with a three-digit index, one sentence, a small picture in a bracket, and a quiet line with an arrow.

- **Use:** The unit of every phone overview (Pirkėjas, Įmonė, Rinka). Three per screen; each opens its own detail screen.
- **Provide:** Label, the sentence with its number in it, an optional picture, one quiet line, the destination.
- **Do not:** The sentence states a finding, not a topic. No more than one picture.
