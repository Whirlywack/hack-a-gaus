# Tag

A small square outlined tag in upper case.

- **Use:** A state or a kind on a row: the stage, the line of work, "Specialių reikalavimų nėra", an urgent distance. Solid accent only for the status of a tender.
- **Provide:** Two or three words, a tone, an optional check icon.
- **Do not:** No rounded pills, no soft fills. Not more than two on one line.
