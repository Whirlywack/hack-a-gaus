# Label

A small upper-case label, alone or with an index number at the far end of its row.

- **Use:** Name a section in `accent`, name a value or a field in `ink-2`. Put a two-digit count or index in `ink-3` at the right end.
- **Provide:** The words. Lithuanian upper case is set by CSS, so write them in sentence case.
- **Do not:** Do not use it for sentences. Do not colour it `urgent` unless it states a deadline within 7 days.
