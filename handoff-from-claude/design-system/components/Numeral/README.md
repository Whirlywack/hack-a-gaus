# Numeral

A figure drawn big, with its unit small beside it.

- **Use:** Use it where the number is the point: days left, a count, a sum. In `urgent` only for 7 days or fewer.
- **Provide:** The figure as text (Lithuanian format: `3,8`, `1 468`) and a unit (`d.`, `mėn.`, `mln. €`).
- **Do not:** Do not set whole sentences in it. No more than three in one strip of cells.
