# RankRows

Ranked rows on one scale: index, name, count, and a thin bar under them.

- **Use:** Who wins at a buyer, who buys in a market. The leader's bar is `ink`, the others `mark`; the unpublished part is hatched and unnumbered.
- **Provide:** Items with a name, a count as words, a number for the bar, an optional typical value; the total the bars are measured against.
- **Do not:** The accent never fills a ranked bar. Do not sort by anything but the count.
