# Answer

The one sentence a screen exists to say, set large, with its second clause dimmed.

- **Use:** Open every screen with it, under the top bar. Write it from the data on that screen; the second clause is the supporting fact.
- **Provide:** A small upper-case meta line (and an optional right-hand one), the sentence, and optionally one supporting line of 14px text.
- **Do not:** Never two on one screen. Never bold. Do not dim more than the second clause.
